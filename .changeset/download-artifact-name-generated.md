A downloaded file's artifact name is generated by the harness instead of taken from the page. The browser's suggested filename was passed straight to the artifact path, so a name the app chose became a path on disk, a `report.json` entry, and an `artifacts.store` key; a name spelling a configured secret could not be redacted afterwards, since the engine cuts it to 64 bytes before any ledger sees it and half a value no longer matches. The suggestion still reaches test code as `DownloadedFile.suggestedFilename`, and the file keeps its extension, so `downloads/003.csv` replaces `downloads/003-<whatever the page said>.csv`.
